# jamesmichaelking.com

Static site for James Michael King Ltd. There is no build step: the HTML and
CSS in this repository are served as they are.

- `index.html` – home page
- `css/app.css` – all styles, written as plain CSS (custom properties and native
  nesting)
- `img/crown.svg` – logo and favicon

To preview, open `index.html` in a browser.

Files are formatted with Prettier's defaults: `npx prettier --write .`
